Made for working all day

Send requests without losing your place

Keep several endpoints open in tabs. Parameters get a field that fits their type, and request bodies start from the schema's example in a JSON editor with folding and search. Your bodies are saved, with one click back to the default.

See every documented response

Read the body, headers, status, time and size next to your request. Every documented response has its example and schema, colored by status code.

Find anything with Ctrl+P

The command palette searches endpoints, tabs, APIs, environments and commands. Filter the list by method or favorites, and copy any request as cURL, fetch, Python, axios, HTTPie or PowerShell.

Switch environments, keep your tabs

Save an API once and move between Development, Staging and Production. Favorites, tabs and drafts stay with you, and each environment keeps its own token.

Sign in once

Log in with the API's OAuth2 password flow, or pick a saved token. The header shows who you are and when the token expires, and every request uses it.

Know when the API changes

New, changed and removed endpoints are marked in the list when the API definition changes, so you don't have to compare anything by hand.

Cookies and JWT tokens in the popup

Save, organize and apply cookies and JWT tokens, grouped by project. Export everything to one compressed file, encrypted if you set a password, or use the optional Google Drive sync to continue on another computer where you left off.

Questions

What is Cookify?
Cookify is a free, open source Chrome extension that turns any Swagger UI page into a Postman-like API client. It adds tabs, environments, saved tokens, a command palette and dark mode to the docs page you already have.
Is Cookify a Postman alternative?
For calling and checking an API that has Swagger docs, yes. It doesn't replace Postman's collections, test scripts or mock servers. See the comparison.
Do I need to import my OpenAPI file?
No. Cookify reads the API document from the Swagger UI page, so your endpoints, schemas and examples are already there. When the API changes, it marks what's new.
Does it change my API or my server?
No. Cookify runs only in your browser, so there's nothing to install on the server. It also works on APIs you don't own, as long as you can open their Swagger UI page.
How do I get dark mode in Swagger UI?
Install Cookify. Its view is dark by default on every Swagger UI page, and you can switch to light from the header. See all the options.
Can I go back to the original Swagger UI?
Yes. Classic view in the header brings it back for that page, and Cookify view returns.
Does it work with Redoc or Scalar?
Not yet. Cookify works on pages that run Swagger UI.
Where is my data stored?
In your browser. There's no account and no analytics, and requests go straight from your browser to your API. Google Drive sync is optional and uses a private app folder in your own Drive.
